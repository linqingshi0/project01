# project01

这是由 linqingshi0 初始化的仓库。包含一个最小的 Python 项目骨架，用于快速开始开发。

## 结构

- src/: 源代码
- requirements.txt: 依赖
- .github/workflows/ci.yml: CI workflow

## 快速开始

1. 克隆仓库
   git clone https://github.com/linqingshi0/project01.git
2. 安装依赖
   python -m pip install -r requirements.txt
3. 运行程序
   python src/main.py
